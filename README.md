# NoteVault SPA
Simple note storing app

GitHub link --> https://github.com/ccharli33/NoteVault-SPA

---

## Description
This project was made using HTML, CSS and JavaScript and is a Single Page Application (SPA)

NoteVault helps users store all their notes in one place, helping them stay more organsie and productive

---

## Features
- Upload notes
- Edit notes
- Download notes as JSON

---

## How to use

-If using VScode, preferably use "Live Server"

-However you can run the HTML file directly from the folder

### Uploading notes:
- Upload .txt file
- Click "Upload"

### Editing notes:
- Edit the file using textbox after uploading
- Click "Save changes"

### Editing existing notes:
- Select note from screen, click on it
- Edit the file using textbox
- Click "Save changes"

### Saving to JSON:
- Select note on the screen, click on it
- Press save to JSON
